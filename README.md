    增高架篇   ：
    这个增高架采用分体式设计，您可以根据您的个人喜好来自由更改尺寸，适用于所有的桌面后侧留有挡板不凡方便拆除的下桌样式。增高架分为三个部分：一、板主体 二、桌面充电站整合拓展坞（左面的腿
    ）
    这里推荐您使用橡木、柚木、胡桃木等木材质地坚硬的木材作为您的增高架板体。切记不建议使用松木等质地较软的品种。
    三、木板面具体尺寸为：
    板面：800×300×15mm
    高：100mm

    板面和腿的连接可分为两种：
一：直接搭放
优点是可活动，更加灵活，可以自由调整您的板面的位置和桌腿之间的距离
缺点也很明显，它的稳固性不是很优秀，但是您可以通过在桌腿的下面粘贴防滑垫来保障整体的稳固性
二、通过粘胶来实现固定
很明显，这种方案的优点是十分的稳固
但是，缺点也很明显。由于是全部粘贴后期的检修将会是您的一大痛点
所以，这里建议您使用第一种方法
  采购建议：推荐使用网购软件进行线上定制成品，不建议您在木材市场线下进行选购。另外快递商简易选择顺丰等口碑较好的快递，并且叮嘱商家在发货时做好保护措施！！
另外，如果您不幸选择了松木等质地较软的木材，不要担心，恭喜您！省了不少钱！
    相比之下如果您的预算比较紧张，可以说选择松木.但需要注意在拿放时轻拿轻放。

    电源与灯光篇：
    灯光部分比较少，所以我会把电源理线放在一块讲，主要的光源只有三个，第一个是主灯、第二个是展示灯、第三个是氛围灯。首先是主灯，为达到更好的效果我这采用的是正常的家居装修的吸顶灯，当然您也可以根据您的喜好来自行选择。
