    增高架篇   ：
    这个增高架采用分体式设计，您可以根据您的个人喜好来自由更改尺寸，适用于所有的桌面后侧留有挡板不凡方便拆除的下桌样式。增高架分为三个部分：一、板主体 二、桌面充电站整合拓展坞（左面的腿
    ） 三、木板面具体尺寸为：
    板面：800×300×15mm
    高：100mm

    板面和腿的连接可分为两种：
一：直接搭放
优点是可活动，更加灵活，可以自由调整您的板面的位置和桌腿之间的距离
缺点也很明显，它的稳固性不是很优秀，但是您可以通过在桌腿的下面粘贴防滑垫来保障整体的稳固性
二、通过粘胶来实现固定
很明显，这种方案的优点是十分的稳固
但是，缺点也很明显。由于是全部粘贴后期的检修将会是您的一大痛点
